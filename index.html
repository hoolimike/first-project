执行步骤：

  1. 粘贴上述命令回车，系统会自动安装 Docker 和环境依赖。
  2. 期间根据提示设置你的后台登录账号、密码和端口（例如端口设为 2053）。

苹果手机 (iOS / iPadOS)

首选工具：Shadowrocket (小火箭)

1. 获取客户端：

国内 App Store 无法下载，需要一个美区 Apple ID。在美区 App Store 搜索下载 Shadowrocket (约 $2.99)。

※ 其他免费替代：Sing-box（美区免费）、Karing（国区免费支持 VLESS）

2. 导入节点步骤：

  1. 打开 Shadowrocket，点击左上角 「扫描二维码」 图标。
  2. 对准第三步生成的二维码扫一扫，节点立即自动保存到首页。
  3. 或者：复制 vless:// 链接，打开小火箭会自动弹窗提示「是否导入」，点击添加即可。
  4. 在节点列表中选中该美国节点，点击顶部开关开启连接，手机即可实现全局美国网络！

2. 导入节点步骤：

  1. 打开 v2rayNG，点击右上角 「+」号。
  2. 选择 「扫描二维码」 或 「从剪贴板导入」。

  4. 打开浏览器访问 ipinfo.io，即可看到手机 IP 已变成美国！

如何验证手机是否已成功变成美国环境？

1. 验证公网 IP 属地

手机打开浏览器访问 ipinfo.io 或 whoer.net，检查 Country 是否显示为 United States 🇺🇸。

2. 验证海外应用解锁

尝试在手机上访问 Google、YouTube、ChatGPT 官方应用，若能无报错秒开且无地域限制，说明美国节点已完全正常运作。

3. 伪装度测试 (100%)

如果是做海外 TikTok 或跨境电商，将手机系统语言设为英文，时区调整为美西时区（如 Los Angeles），关闭定位服务，伪装度即可达到 100%。
